# Security Policy

## Supported Versions

We support the latest version of this CLI tool. Please ensure you're using the most recent version.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing security@relewise.com

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

We will respond within 48 hours and provide updates as we investigate and address the issue.
